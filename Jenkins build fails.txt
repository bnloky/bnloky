####################     Microservices #########################
       As each module is an independently deployable unit, you have considerable choices to pick the right technology for the Job. For example, 
the module that deals with Machine Learning could be written in Python, and the module that deals with Calculations is written in Java.
And these modules could communicate with each other via REST, GraphQL, or Events.
Microservices also allow you to choose a polyglot persistent system. 
You can use MySQL for transaction management, MongoDB for document storage for specific modules, and so on.
